## 1. 기술 스택

| 항목 | 기술 |
|------|------|
| 프레임워크 | React 18 (함수형 컴포넌트, Hooks) |
| 번들러 | Vite |
| 언어 | TypeScript (strict) |
| 다국어 | i18next (ko/en/ja/zh/vi 5개 locale) |
| 스타일 | CSS Variables (다크/라이트 테마), 인라인 스타일 |
| 아이콘 | lucide-react |
| 언어 감지 | tinyld (n-gram, ~30KB) |
| 상태 관리 | React useState/useRef/useContext (외부 라이브러리 없음) |
| 통신 | WebSocket (실시간 합성) + Axios (REST API) |
| 인증 상태 | localStorage + Context |

## 3. 페이지별 명세

### 3.1 SynthesisPage (메인 합성 페이지)

**주요 상태:**
```typescript
text: string                    // 입력 텍스트
opts: SynthesisOptions          // 합성 파라미터 (voice_id, language, speed, ...)
voices: Voice[]                 // 서버에서 10초마다 폴링
engineHealth: EngineHealth      // 엔진 상태
playbackRate: number            // 재생 속도 (클라이언트 사이드)
autoDetectLang: boolean         // 자동 언어 감지 토글
effectiveTab: 'tone'|'params'|'process'  // 파라미터 패널 활성 탭
```

**레이아웃:**
```
┌─────────────────────────────────────────────┐
│ 텍스트 입력 영역                              │
│ (드래그앤드롭, 파일 로드, 카라오케 오버레이)   │
├──────────────────────┬──────────────────────┤
│ 음성·엔진·언어 선택  │ 파라미터 패널 (3탭)  │
│                      │ tone / params / process│
└──────────────────────┴──────────────────────┘
│ 합성 버튼 · 중단 · Playback 컨트롤           │
├─────────────────────────────────────────────┤
│ 합성 이력 테이블                              │
└─────────────────────────────────────────────┘
```

**Tone 탭 (감정 프리셋):**

| 프리셋 | temperature | top_p | playbackRate |
|--------|-------------|-------|--------------|
| 기본 | 1.0 | 1.0 | 1.0 |
| 활기차게 | 1.3 | 0.95 | 1.1 |
| 부드럽게 | 0.75 | 0.88 | 0.92 |
| 차분하게 | 0.7 | 0.85 | 0.9 |

- vLLM: 클릭 시 temperature + top_p + playbackRate 동시 변경
- Supertonic: 클릭 비활성 (temperature/top_p 미지원)

**Params 탭:**
- Supertonic 말투 스타일 칩: `기본 / M1 / M2 / M3 / M4 / M5 / F1 / F2 / F3 / F4 / F5` (isSupertonic일 때만 표시)
- 감성도(Temp): range slider (0.1~2.0) — vLLM 전용
- 다양성(Top-P): range slider — vLLM 전용
- 청크 크기: 2KB ~ 64KB 선택
- 코덱 청크: 4~39 프레임 선택

**Process 탭:**
- ITN 도메인 선택 (한국어 전용)
- 문장 분할, 정규화 (배치 전용)
- ICL, 고음질, 팝음방지, 무음제거, 초성보존, 억양조절, CER, 캐시, DSP 프로파일

**자동 언어 감지:**
```typescript
// 250ms 디바운스로 텍스트 변경 감지
// tinyld 신뢰도 0.15 이상일 때만 자동 전환
// 감지 언어 → 음성 자동 매칭 (pickVoiceForLanguage)
```

**10초 폴링 (useSynthesis):**
- `/v1/voices` + `/v1/health` 동시 요청
- 현재 voice_id가 valid(enabled & ready)이면 opts 보존 (사용자 선택 유지)
- invalid할 때만 pickVoiceForLanguage로 폴백 재선택

### 3.3 SettingsPage (설정 탭)

**섹션:**
1. **합성 기본값**: 엔진, 음성, 언어, 파라미터
   - **NumberWithPresetChips 컴포넌트** (v0.9.8+): 코덱 청크 / 무음 패딩 / 최대 무음 / 종료 무음 / 페이드 / 문장간 / hangover / 할루시네이션 가드 8개 항목
   - hybrid controlled input — 직접 타이핑 (`<input type=number>` + min/max/step) + chip 클릭으로 추천값 즉시 채우기 + ★ 별표로 권장값 표시
   - localInput state로 빈 input 일시 허용 (backspace UX 보장), onBlur 시 이전 valid 값으로 복원
2. **품질·로직**: boolean 칩 배열 (ITN, CER, ICL, split 등)
3. **ICL 언어 칩**: ICL이 ON일 때만 표시 — KO/EN/JA/ZH/DE/FR/ES/IT/PT/RU 다중 선택 (default `"ko"`)
4. **ITN 도메인 편집기**: 선택한 도메인의 JSON 규칙 직접 편집
5. **음성 관리**: VoiceManager 컴포넌트 (업로드/삭제/활성화)
6. **사용자 관리**: UserManager 컴포넌트
7. **인프라 설정**: 캐시 TTL, 동시성, 메모리 쿼터
8. **보안 설정**: JWT 만료, Rate limit
9. **Webhook/SMTP**: 알림 설정

**v0.9.8 변경**:
- EOS Suffix UI 블록 제거 — `prepare_engine_sentence` 의 `::` 변환이 EOS 억제 충분 (backend `default_eos_suffix` 키는 admin API 비상용으로 보존)
- voice picker 자동 라우팅: vLLM 지원 언어 (`ko/en/zh/ja/de/fr/es/it/pt/ru`) → vLLM voice 필터 + `language` 일치만 노출. 그 외 → Supertonic voice. 매칭 0개 시 selector 비어있음 + 이전 `opts.voice_id` 그대로 유지

## 4. 핵심 훅 명세

### 4.1 `useSynthesis(token, defaults, active)`

```typescript
// 반환값
opts: SynthesisOptions        // 현재 합성 파라미터
setOpts: Dispatch             // opts 업데이트
voices: Voice[]               // 사용 가능한 음성 목록
engineHealth: EngineHealth    // 엔진 상태

// 주요 로직
// - 10초마다 /v1/voices + /v1/health 폴링
// - 서버 settings → opts 초기값 적용 (SYNTH_KEY_MAP 매핑)
// - voice_id localStorage 저장 (tts_synth_voice_id)
// - 현재 선택 음성이 valid하면 폴링 시 덮어쓰지 않음 (valid = enabled & ready)
```

**SYNTH_KEY_MAP (서버 설정 키 → opts 키):**

```typescript
'supertonic_default_style': 'supertonic_style',
'supertonic_default_total_steps': 'supertonic_total_steps',
'default_icl': 'use_icl',
// ...기타 파라미터
```

### 4.2 `useTTS()`

```typescript
// 반환값
isGenerating: boolean
synthStage: 'idle' | 'connecting' | 'waiting' | 'streaming'
stageElapsedMs: number              // waiting 경과 시간 (ms)
metrics: TTSMetrics | null          // TTFB, RTF, CER, trace_id 포함
sentenceTimings: SentenceTiming[]   // 카라오케 타이밍
voiceFallback: VoiceFallbackInfo | null   // from/to/reason
engineFallback: EngineFallbackInfo | null // reason + source('started'|'done')
wsError: string | null
synthesizeStream(opts, token): Promise<void>
abort(): void
```

**TTSMetrics.trace_id** — WS `done` 프레임의 trace_id. 피드백 제출 시 `FeedbackSubmitBody.trace_id`로 전달하여 `audit_logs`와 cross-reference.

**타임아웃**:
- WS 연결: 8s
- TTFB 경고: 30s (큰 텍스트 + 콜드 vLLM 고려)
- TTFB 자동 중단: 150s (콜드 스타트 90~120s 흡수)

## 10. 주요 컴포넌트 상호작용 다이어그램

```
SynthesisPage
  ├─ useSynthesis (10s 폴링, opts/voices/engineHealth)
  ├─ useTTS (WS 연결, 스트리밍)
  ├─ LangSelect (언어 드롭다운 + 자동감지)
  ├─ [Tone 탭] EMOTION_PRESETS → opts.temperature/top_p 변경
  │                             → isSupertonic 시 아무 동작 없음
  ├─ [Params 탭] Supertonic 스타일 칩 → opts.supertonic_style 변경
  ├─ [Params 탭] 슬라이더 → opts.temperature/top_p 변경
  └─ synthesizeStream({ ...opts, text }) → WS 연결 → PCM 스트림

AdminPage
  ├─ OverviewTab (감사로그 그리드)
  ├─ DiagnosticsTab (엔진 상태)
  └─ LogsTab (실시간 로그)

SettingsPage
  ├─ fetchData() → /v1/admin/settings (initialSettings merge)
  ├─ saveSettings() → PATCH /v1/admin/settings (changedFields only)
  └─ ICL 언어 칩 → icl_enabled_languages 문자열 업데이트
```
