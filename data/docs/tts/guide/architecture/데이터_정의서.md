# 데이터 정의서 (Data Dictionary)

- **작성일**: 2026-07-20
- **범위**: DB 테이블 5개 + 파일 시스템 데이터 + Redis KV + 설정 (`global_settings` value 구조)
- **대상**: 개발자·운영자·감사인
- **원본 코드**: [`qwen3-tts-api/db/models.py`](../../../qwen3-tts-api/db/models.py) · [`db/manager.py`](../../../qwen3-tts-api/db/manager.py) · [`clients/redis_client.py`](../../../qwen3-tts-api/clients/redis_client.py)
- **관련 문서**: [DB ERD](DB_ERD_2026-07-20.md) · [인프라 구조](../../deploy/인프라_구조.md)

## 표기 규칙
- **필수**: NOT NULL · 값 없이 insert 불가
- **선택**: NULL 허용 (legacy row 호환 or 상황에 따라)
- **인덱스**: idx (일반) · uk (unique) · pk (primary key)
- **형식**: SQLAlchemy Mapped 타입 (DB 실제 타입은 PG 기준)

## 1. `users` — 계정·인증

| 컬럼 | 형식 | 필수 | 인덱스 | 기본값 | 의미·규칙 | 예시 |
|------|------|------|--------|--------|----------|------|
| `id` | int (auto) | ✅ | pk | — | 자동 증분 · 내부 참조용 | `1`, `42` |
| `username` | varchar(50) | ✅ | uk · idx | — | 로그인 아이디 · alnum + `._-` · 대소문자 구분 · 변경 불가 | `admin`, `mario`, `super` |
| `password_hash` | varchar(255) | ✅ | — | — | bcrypt 해시 · 원본 미저장 | `$2b$12$...` |
| `role` | varchar(20) | ✅ | — | `"user"` | `user` · `admin` · `super_admin` · 승격 시 `role_changed_at` 갱신 필수 | `admin` |
| `status` | varchar(20) | ✅ | — | `"active"` | `active` · `disabled` · disabled 는 로그인 차단 | `disabled` |
| `api_key` | varchar(100) | 선택 | uk · idx | `NULL` | SHA-256 해시 저장 · 발급 시 원본은 사용자에게만 1회 노출 | `a3f...` (해시) |
| `api_key_hint` | varchar(20) | 선택 | — | `NULL` | 마지막 4자리 표시용 · UI 식별 (`sk-...wxyz`) | `wxyz` |
| `api_key_last_used_at` | timestamp+tz | 선택 | — | `NULL` | 마지막 사용 시각 · Redis 스로틀(60s) 로 write 부하 방지 | `2026-07-20T10:15:00+09:00` |
| `created_at` | timestamp+tz | ✅ | — | now(UTC) | 계정 생성 시각 (UTC 저장 · UI 는 로컬 표시) | `2026-07-01T00:00:00+00:00` |
| `password_changed_at` | bigint (unix) | 선택 | idx | `NULL` | 마지막 비밀번호 변경 unix ts · **JWT `iat` 비교로 옛 세션 무효화** (Bug 202 fix) | `1721438400` |
| `role_changed_at` | bigint (unix) | 선택 | idx | `NULL` | 마지막 권한 변경 unix ts · 강등 즉시 반영 | `1721438400` |
| `org_id` | varchar(50) | 선택 | idx | `"default"` | 멀티테넌트용 조직 ID · 통계·감사 필터에 활용 | `default`, `acme` |

**중요 규약**
- 비밀번호 변경 시 반드시 `password_changed_at = int(time.time())` 갱신 → JWT invalidate
- role 변경 시 반드시 `role_changed_at = int(time.time())` 갱신 → 세션 무효화
- `username` 은 lifecycle 동안 변경 안 함 (감사 log 참조 유지)
- api_key 발급/폐기 흐름: 발급 시 hash 저장 + hint · 폐기 시 `api_key=NULL`

## 2. `voices` — 화자 메타

| 컬럼 | 형식 | 필수 | 인덱스 | 기본값 | 의미·규칙 | 예시 |
|------|------|------|--------|--------|----------|------|
| `voice_id` | varchar(100) | ✅ | pk | — | 내부 식별자 · 변경 시 참조 깨짐 · prefix 로 엔진 자동 판정 (`supertonic_` `qwen_st_`) | `qwen_kor_female_02_5s` |
| `name` | varchar(100) | ✅ | — | — | 표시명 (한글 지원) · admin UI 편집 가능 | `수아`, `도현`, `Henry` |
| `language` | varchar(50) | ✅ | idx | — | ISO 639-1 (`ko`·`en`·`ja`·`zh` 등 31종) | `ko` |
| `gender` | varchar(20) | ✅ | idx | — | `male` · `female` · `neutral` · 공개 ID 접두 M/F/N 결정 | `female` |
| `description` | text | 선택 | — | `NULL` | 자유 설명 (톤·용도 힌트) | `고음역 감정 풍부한 성우` |
| `ref_audio` | varchar(255) | 선택 | — | `NULL` | ref_audio 상대경로 (`./samples/xxx.wav`) · vLLM 만 사용 · Supertonic 은 `.json` (Voice Builder) | `./samples/D_5s.wav` |
| `ref_text` | text | 선택 | — | `NULL` | ref_audio 발화 텍스트 (ICL 정확도용) | `모든 이들 앞에서 정의를 요구할 겁니다.` |
| `enabled` | boolean | ✅ | idx | `true` | false 면 목록·합성 제외 · disable 은 삭제와 다름 | `true` |
| `engine` | varchar(20) | ✅ | idx | `"vllm"` | `vllm` 또는 `supertonic` · 라우팅 결정 · v0.9.8 이전엔 prefix 추론 (memory 참조) | `vllm` |
| `ref_audio_duration_ms` | int | 선택 | — | `NULL` | 등록 시 librosa 로 측정 · NULL 이면 ICL prefix trim 안 함 | `5320` |
| `descriptor` | varchar(50) | 선택 | — | `NULL` | 공개 ID 조합용 특성어 · NULL 이면 자동 공개 ID 미생성 | `bright`, `soft`, `deep` |
| `public_id` | varchar(120) | 선택 | idx | `NULL` | 외부 API 핸들 · 배정 후 **불변** · UNIQUE 부분(NULL 다중 허용) | `F_ko_bright`, `M_ko_deep` |
| `created_at` | timestamp+tz | ✅ | — | now(UTC) | 등록 시각 | `2026-07-01T00:00:00+00:00` |

**공개 ID 규칙**
- 형식: `{M|F|N}_{language}_{descriptor}` (예: `F_ko_bright`)
- 생성: `compute_public_id(voice)` (`services/tts/voice_alias.py`)
- 불변: 한 번 배정된 `public_id` 는 변경 안 함 (클라이언트 코드 안정성)

**yaml 미러**
- 마스터: DB
- 미러: `data/voices/voices.yaml` — API 편집 시 자동 dump (`db_manager.dump_voice_registry_to_yaml`)
- 시드: `voices` 테이블 비어있을 때 yaml → DB (조건부, 관리자 편집 안 덮어씀)

**엔진 라우팅** (`services/tts/common.py`)
1. `engine` 필드 (명시)
2. 없으면 (legacy) prefix 추론:
   - `supertonic_*`, `qwen_st_*` → supertonic
   - 그 외 → vllm

## 6. 파일 시스템 데이터

### 6.1 `data/voices/samples/*.wav|mp3` — ref_audio

| 항목 | 값 |
|------|-----|
| 경로 | `data/voices/samples/{basename}.{wav|mp3|flac|ogg|m4a}` |
| 마운트 | vllm-a/b (`ro`) · api (`rw`) — 3서비스 공유 |
| 서빙 | `GET /samples/{path}` (routers/voices.py:1353) · no-cache · basename fallback |
| 참조 | `voices.ref_audio` → `./samples/xxx.wav` |
| 형식 | 16-bit PCM WAV 권장 · 5~11초 · 24kHz mono (자동 정규화) |
| 마이그레이션 | v0.9.9+ flat (gender 하위폴더 제거) · memory `44058ac` |
| 백업 | `data/voices/_backups/voices_full/` |

### 6.2 `data/voices/voices.yaml` — DB 미러

- 형식: YAML dict (`voices:` root)
- 각 항목: voice_id + name/language/gender/description/ref_audio/ref_text/enabled/descriptor
- 갱신: API voice CRUD 시 자동 dump
- 시드: 테이블 empty 시 yaml → DB (조건부)

### 6.3 `data/itn/itn_builtin.json` — ITN 사전 시드

- 형식: `{eng_tech, eng_proper, eng_common, math_sym, units_sino, currency, arrows, punct, programming, url_sym, native_units}`
- 시드: `global_settings.itn_builtin` 키 없을 때 이 파일로 seed
- 편집 후: `docker restart tts-api` 로 재로드 (또는 admin UI 로 DB 갱신)

### 6.4 `data/cache/audio_norm/*.wav` — ref_audio 정규화 캐시

- 이름: `{md5(abs_path:mtime:strip_flag)}_24k_mono.wav`
- 생성: `_normalize_ref_audio_cached` (`engines/vllm_voice.py`)
- 무효화: 원본 파일 mtime 변경 시 자동 재생성

### 6.5 `logs/{api,engine,redis,postgres,nginx}/*.log`

- Docker `json-file` driver · rotation `max-size=200m max-file=5`
- 서비스별 폴더 분리 (호스트 접근용 bind mount)

## 7. Redis KV 데이터 (schema-less)

### 7.1 캐시류

| 키 | 형식 | TTL | 용도 |
|----|------|-----|------|
| `tts:audio:<sha1>` | binary (WAV) | 24h (설정) | 합성 결과 캐시 |
| `tts:reg:<addr>:<voice_id>` | string (bool) | 세션 | vLLM voice 등록 상태 |
| `tts:trace:<trace_id>` | JSON (spans) | 60s | LatencyTracer (프론트 폴링) |

### 7.2 조정류

| 키 | 형식 | TTL | 용도 |
|----|------|-----|------|
| `tts:cb:<name>` | JSON (state) | 세션 | 회로차단기 상태 (closed/open/half_open) |
| `tts:sem:<name>` | integer (count) | 세션 | 분산 세마포어 카운터 |
| `tts:lac:<addr>` | integer (count) | 세션 | Load Balance 카운터 (vLLM 부하분산) |
| `tts:ratelimit:<ip>` | integer + TTL | 60분 창 | IP당 요청 수 |
| `tts:leader` | string (worker_id) | ~5s (heartbeat) | 리더 선출 (cleanup 등 단일 실행 태스크) |

### 7.3 Pub/Sub 채널

| 채널 | 페이로드 | 트리거 |
|------|---------|--------|
| `config_update` | dict (변경 설정) | 관리자 UI 설정 저장 시 |
| `itn_update` | dict (변경 룰) | ITN 룰 편집 시 |

수신 처리: `db_manager.register_config_callback` 로 등록된 콜백들 순차 호출.

## 8. 데이터 관계·정합성 (요약)

### 8.1 loose FK
DB 레벨 FK 없음 · 애플리케이션 참조 정합만. 이유: 감사 요구 (user/voice 삭제 후에도 이력 유지).

- `audit_logs.username` → `users.username` (loose)
- `audit_logs.voice_id` → `voices.voice_id` (loose, nullable)
- `user_feedback.username` → `users.username` (loose)
- `user_feedback.voice_id` → `voices.voice_id` (loose, nullable)
- `user_feedback.trace_id` ↔ `audit_logs` (feedback 만 나오는 방향, id 매핑 loose)

### 8.2 마이그레이션 정책
- **자동**: SQLAlchemy `Base.metadata.create_all()` (테이블만)
- **수동 필요**: 컬럼 추가·변경·인덱스 재구성 (alembic 없음, 개선 과제)
- **시드**: `voices.yaml` · `itn_builtin.json` (조건부 · 관리자 편집 안 덮어씀)

### 8.3 UUID·TZ 규약
- 시각: `timestamp with time zone` · **UTC 로 저장** · UI 는 로컬 시간대 변환
- ID: 정수 자동 증분 (auto-increment) · UUID 안 씀 (외부 노출 없어서 불필요)
- 예외: `trace_id` 는 UUID4 hex 32자 (uuid.uuid4().hex)

## 9. 개인정보·민감 데이터 취급

| 항목 | 위치 | 정책 |
|------|-----|------|
| password | `users.password_hash` | bcrypt 12 라운드 · 원본 저장 금지 |
| API key | `users.api_key` | SHA-256 해시 저장 · 원본은 발급 시 1회만 사용자에게 노출 |
| 합성 텍스트 | `audit_logs.text` · `user_feedback.text_snippet` | 프로덕션 감사 요구 상 저장 · GDPR 대응 시 삭제 절차 필요 |
| 이메일 | `settings.email_*` · `settings.smtp_password` | JSON 저장 · smtp_password 는 GET/PATCH 응답 마스킹 (memory `29d04bb`) |
| IP | `tts:ratelimit:<ip>` | Redis TTL 60분 자동 삭제 |

### 삭제 요청 대응 (사용자 요청 시)
1. `users` — 물리 삭제 대신 `status='deleted'` + PII 필드 마스킹
2. `audit_logs` — username 유지 (감사) · text 마스킹 (선택적)
3. `user_feedback` — comment 마스킹 or 삭제
