# Qwen3-TTS API 개발자 가이드 (Quickstart)

> 5분 만에 첫 합성 호출 → 운영 통합까지의 cheatsheet. Swagger 전체 스펙은 `https://<IP>:<PORT>/docs` 참고.

> ⚠️ **인증 OFF 모드 (사내망 배포)**: 운영자가 `TTS_AUTH__DISABLED=true`로 배포한 경우 아래 토큰/API Key 절차는 **불필요**합니다. `Authorization` 헤더 없이 바로 합성 호출 가능. ON/OFF 여부는 운영자에게 확인하세요.

---

## 1. Hello World (60초)

**인증 ON 모드 (기본)**
```bash
# 1) 토큰 발급 — OAuth2 password grant (form-encoded, JSON 아님)
TOKEN=$(curl -s -X POST https://<IP>:<PORT>/v1/auth/token \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -d "username=user&password=<pw>" | jq -r .access_token)

# 2) 합성 (한국어 기본 음성)
curl -X POST https://<IP>:<PORT>/v1/tts/synthesize \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text":"안녕하세요. Qwen3-TTS 시스템입니다."}' \
  -o hello.wav
```

**인증 OFF 모드 (사내망 전용)**
```bash
# 토큰 발급 생략 — Authorization 헤더 없이 바로 호출
curl -X POST https://<IP>:<PORT>/v1/tts/synthesize \
  -H "Content-Type: application/json" \
  -d '{"text":"안녕하세요. Qwen3-TTS 시스템입니다."}' \
  -o hello.wav
```

본문에 `text`만 있으면 동작합니다. voice·engine·language·옵션은 전부 서버 기본값 적용.

> **ON 모드일 때 B2B는 토큰 대신 API Key 권장**: 운영자에게 `sk-...` 발급받아 `Authorization: Bearer sk-...`로 영구 사용. 만료·갱신 없음. [`API_Key_관리.md`](./API_Key_관리.md) 참조.

## 2. 엔진 자동 라우팅 — 절대 헷갈리지 마세요

**`engine` 필드는 거의 보낼 일이 없습니다.** 서버가 자동 결정합니다:

```
1. voice_id가 supertonic_* 로 시작 → Supertonic
2. language가 vLLM 미지원 (예: vi, ar, hi) → Supertonic
3. 그 외 → vLLM
```

따라서 클라이언트는 **voice_id 또는 language만 정확히** 보내면 끝.

| 상황 | 보내는 값 | 결과 엔진 |
|---|---|---|
| 한국어, 기본 음성 | `{"text":"..."}` | vLLM |
| 한국어, 특정 음성 | `{"text":"...","voice_id":"qwen_kor_male_01_5s"}` | vLLM |
| 베트남어 | `{"text":"...","language":"vi"}` | Supertonic (자동) |
| Supertonic 내장 음성 명시 | `{"text":"...","voice_id":"supertonic_m1"}` | Supertonic |

### 자동 Fallback
vLLM이 과부하(Circuit Breaker OPEN)이면 vLLM 요청도 Supertonic으로 자동 swap됩니다. 클라이언트 페이로드는 변경 없이 동일 호출 가능. 발생 시 응답 헤더에 `X-Engine-Fallback: true`.

## 3. 음성 카탈로그 — 동적으로 가져오세요

음성 목록은 운영 중 추가/삭제됩니다. **하드코딩 금지.** 부팅 시 한 번 불러와 캐시:

```bash
curl -H "Authorization: Bearer $TOKEN" "https://<IP>:<PORT>/v1/voices?language=ko"
# 인증 OFF 모드면 -H 생략 가능
```

응답은 운영자가 활성화한 voice만 포함됩니다 (`?enabled_only=true` 기본). 비활성화된 voice는 노출되지 않으므로 응답에 있는 voice_id만 사용하면 안전합니다.

```json
{
  "voices": [
    {
      "voice_id": "qwen_kor_female_01_5s",
      "name": "아이유 5s",
      "language": "Korean",
      "gender": "female",
      "engine": "vllm",
      "supports_all_languages": false,
      "ready": true,
      "enabled": true
    },
    {
      "voice_id": "supertonic_m1",
      "name": "남성 1",
      "engine": "supertonic",
      "supports_all_languages": true
    }
  ],
  "default_voice_id": "qwen_kor_female_01_5s"
}
```

### 주요 빌트인 음성 (참고용)

> 정확한 활성 voice 목록은 항상 `GET /v1/voices` 응답을 기준으로 사용하세요. 운영 중 추가·비활성화될 수 있습니다.

| voice_id | 엔진 | 언어 | 특징 |
|---|---|---|---|
| `qwen_kor_female_01_5s` | vLLM | 한국어 | 기본 여성 (아이유 5s 톤) |
| `qwen_kor_female_02_5s` | vLLM | 한국어 | 여성 성우 톤 |
| `qwen_kor_male_01_5s` | vLLM | 한국어 | 기본 남성 |
| `qwen_st_m1` ~ `m5` | vLLM | 한국어 | Qwen3-TTS 내장 남성 5종 |
| `qwen_st_f1` ~ `f5` | vLLM | 한국어 | Qwen3-TTS 내장 여성 5종 |
| `supertonic_m1` ~ `m5` | Supertonic | 31개 언어 | 다국어 내장 남성 5종 |
| `supertonic_f1` ~ `f5` | Supertonic | 31개 언어 | 다국어 내장 여성 5종 |

> 영어·중국어·일본어 등 비한국어는 Supertonic이 31개 언어를 지원합니다. `language` 필드만 지정하면 자동 라우팅되므로 별도 voice 선택 없이 사용 가능.

## 4. 옵션 매트릭스 — 어느 옵션이 어느 엔진에?

**공통 (둘 다 적용)**

| 옵션 | 타입 | 범위 | 비고 |
|---|---|---|---|
| `text` | string | 1~5000 | 필수 |
| `voice_id` | string | — | 미지정 시 default |
| `language` | string | ko, en, zh, ja, de, fr, es, it, pt, ru + (Supertonic) vi, ar, hi, nl, pl, sv, tr, uk, da, fi, hu, cs, sk, ro, bg, hr, sl, lt, lv, et, el | |
| `speed` | float | 0.5 ~ 2.0 | 재생 속도 |
| `use_itn` | bool | — | 숫자/단위 정규화 (ko만 의미 있음) |
| `itn_domain` | enum | standard, finance, casual, commerce, mobility, aicc, media, tech, healthcare, education, game | |
| `use_normalize` | bool | — | 피크 볼륨 정규화 |
| `use_micro_fade` | bool | — | 청크 경계 fade |
| `silence_padding_ms` | float | 0~2000 | 첫 PCM 앞 무음 (cold-start 완화) |
| `audio_format` | enum | wav, mp3, ogg, flac | mp3는 ffmpeg 필요 |
| `bypass_cache` | bool | — | 캐시 우회 (디버깅용) |

**vLLM 전용** (Supertonic에 보내면 조용히 무시)

| 옵션 | 타입 | 범위 | 비고 |
|---|---|---|---|
| `temperature` | float | 0.1 ~ 2.0 | 샘플링 다양성 |
| `top_p` | float | 0.1 ~ 1.0 | top-p sampling |
| `use_icl` | bool | — | 음성 클로닝 (voice ref_audio 필요) |
| `use_silence_guard` | bool | — | 모델 환각(반복/잡음) 차단 |
| `use_silence_lookback` | bool | — | 초성 보호 lookback buffer |
| `high_fidelity` | bool | — | 고품질 DSP (vocoder_bridge) |
| `smart_prosody` | bool | — | 구두점 기반 prosody |
| `initial_codec_chunk_frames` | int | 4 ~ 64 | 첫 청크 프레임 수 |

**Supertonic 전용** (vLLM에 보내면 조용히 무시)

| 옵션 | 타입 | 범위 | 비고 |
|---|---|---|---|
| `supertonic_total_steps` | int | 1 ~ 24 | diffusion 스텝. 낮을수록 빠름 |
| `supertonic_style` | enum | M1~M5, F1~F5 | voice_id 미지정 시 사용 |

**스트리밍 전용** (`/v1/tts/synthesize/stream`, WS만)

| 옵션 | 타입 | 비고 |
|---|---|---|
| `chunk_size` | int | 청크 바이트 크기 |

> **핵심 원칙**: 엔진 전용 옵션을 보내도 에러는 안 납니다. 받는 엔진은 자기가 쓰는 것만 골라 쓰고 나머진 무시. 옵션 누락도 OK — 서버 기본값 사용.
>
> **기본값 확인**: 각 옵션의 platform default는 [`합성_파라미터.md`](../engine/합성_파라미터.md)에 정리돼 있습니다. platform 운영자가 변경할 수 있으므로 정확한 현재값은 `GET /v1/capabilities` 또는 `GET /v1/admin/settings`로 확인하세요. 특정 동작을 가정하는 통합 코드라면 해당 옵션을 **명시적으로 전달**하는 것을 권장합니다.

## 5. 엔드포인트 모음

| 엔드포인트 | 용도 | 응답 |
|---|---|---|
| `POST /v1/tts/synthesize` | 단일 텍스트 동기 합성 | binary audio |
| `POST /v1/tts/multi` | **다중 텍스트 배치 합성** (v0.9.2+) — `texts[]` 배열 → 병합 wav | binary audio |
| `POST /v1/tts/synthesize/stream` | HTTP chunked 스트리밍 | binary chunked |
| `WS /v1/tts/synthesize/ws` | WebSocket 양방향 스트리밍 | binary frames |
| `GET /v1/voices` | 음성 카탈로그 | json |
| `GET /v1/capabilities` | 엔진/언어/옵션 능력 매트릭스 | json (SDK용) |
| `POST /v1/feedback` | 사용자 피드백 제출 | json |
| `GET /docs` | Swagger UI | html |

## 6. 응답 헤더 레퍼런스 (binary 응답 공통)

| 헤더 | 의미 | 활용 |
|---|---|---|
| `X-Trace-Id` | 합성 trace_id | 피드백 제출 시 같이 보내기 (audit 연결) |
| `X-TTFB-Ms` | 첫 바이트 지연 | UX 모니터링 |
| `X-Duration-Seconds` | 생성 음성 길이 | UI 표시 |
| `X-Sample-Rate` | 샘플레이트 | 24000 (vLLM) / 44100 (Supertonic) |
| `X-Engine` | 실제 사용 엔진 | "vllm" / "supertonic" |
| `X-Engine-Fallback` | 자동 fallback 발생 | "true"면 음색 변경 알림 표시 |
| `X-Engine-Fallback-Reason` | fallback 사유 | "vllm_cb_open" |
| `X-Voice-Fallback` | voice 자동 변경 | 잘못된 voice → fallback voice로 교체됨 |
| `X-Audio-Format` | 실제 출력 포맷 | mp3 요청해도 ffmpeg 없으면 wav |
| `X-RTF` | Real-Time Factor | < 1.0 = 실시간보다 빠름 |

**브라우저 fetch에서 읽으려면** CORS의 `expose_headers`에 등록되어 있어야 합니다 (서버에서 이미 처리됨).

## 7. 에러 코드 매트릭스

| 코드 | 의미 | 대응 |
|---|---|---|
| 400 | 잘못된 요청 (텍스트 공백, 미지원 포맷 등) | 입력 검증 |
| 401 | 인증 실패 / 토큰 만료 | 재로그인 또는 refresh |
| 403 | 권한 부족 (admin 전용 호출 등) | 권한 확인 |
| 413 | 페이로드 초과 (음성 업로드 10MB 등) | 파일 분할 |
| 422 | 의미적 오류 (비활성 voice, 잘못된 파라미터) | voice 활성 상태 확인 |
| 429 | Rate limit / 백프레셔 | exponential backoff |
| 500 | 서버 내부 오류 | retry + 알림 |
| 503 | Service unavailable | Circuit Breaker OPEN / 점검모드 / Emergency. **fallback enabled면 vLLM 요청은 503 대신 Supertonic으로 자동 전환됨** |
| 507 | 저장 공간 부족 | 운영팀 알림 |

## 8. 자주 쓰는 패턴

### 8.1 다국어 자동 라우팅 (사용자가 언어 선택)
```bash
# 베트남어 — voice 지정 안 해도 Supertonic 자동 선택, 기본 voice 사용
curl -X POST .../v1/tts/synthesize \
  -d '{"text":"Xin chào","language":"vi"}'
```

### 8.2 ICL 음성 클로닝 (vLLM 전용)
```bash
# ref_audio 등록된 voice라면 use_icl=true로 음색 정밀 복제
curl -X POST .../v1/tts/synthesize \
  -d '{"text":"안녕하세요","voice_id":"qwen_kor_female_01_5s","use_icl":true}'
```

### 8.3 스트리밍 (TTFB 최소화)
```javascript
const res = await fetch('/v1/tts/synthesize/stream', {
  method: 'POST',
  headers: { Authorization: `Bearer ${token}`, 'Content-Type': 'application/json' },
  body: JSON.stringify({ text: '...', use_split: true })
})
const traceId = res.headers.get('X-Trace-Id')
const reader = res.body.getReader()
while (true) {
  const { value, done } = await reader.read()
  if (done) break
  // value는 WAV 청크. AudioContext에 push 또는 MSE에 append
}
```

### 8.4 Fallback 감지 및 사용자 알림
```javascript
const res = await fetch('/v1/tts/synthesize', { ... })
if (res.headers.get('X-Engine-Fallback') === 'true') {
  toast.info('서버 과부하로 보조 엔진으로 전환되었습니다. 음색이 다를 수 있습니다.')
}
```

### 8.5 피드백 제출 (trace_id 활용)
```bash
curl -X POST .../v1/feedback \
  -d '{
    "comment": "카페 발음이 어색함",
    "trace_id": "abc123",
    "voice_id": "qwen_kor_female_01_5s",
    "language": "ko",
    "engine": "vllm",
    "text_snippet": "오늘 카페에서 만나자"
  }'
```

## 9. SDK 사용 권장

직접 wrapper 짜는 대신 공식 SDK가 빠릅니다:

- **Python**: `sdk/python/aicess_tts/` → `pip install -e ./sdk/python` 후 `from aicess_tts import Client`
- **TypeScript/JS**: `sdk/typescript/` → `npm install` 후 `import { Client } from 'aicess-tts'`

SDK는 `/v1/capabilities` 응답으로 voice 카탈로그·옵션 매트릭스를 자동 검증해 잘못된 옵션을 컴파일/런타임 단계에서 차단합니다.

## 10. Capability 자가 검증 (고급)

런타임에 서버 능력을 확인해 클라이언트 측 가드를 짤 수 있습니다:

```bash
curl https://<IP>:<PORT>/v1/capabilities
```

```json
{
  "engines": {
    "vllm": {
      "languages": ["ko","en","zh","ja","de","fr","es","it","pt","ru"],
      "supported_options": ["temperature","top_p","use_icl","use_silence_guard","high_fidelity",...],
      "features": ["icl","streaming","high_fidelity"]
    },
    "supertonic": {
      "languages": ["ko","en","ja","vi","ar","hi","nl",...],
      "supported_options": ["supertonic_total_steps","supertonic_style"],
      "features": ["multilingual","cpu_inference"]
    }
  },
  "language_routing": { "vi": "supertonic", "ko": "vllm", ... },
  "fallback_enabled": true,
  "default_voice_per_language": { "ko": "qwen_kor_female_01_5s", ... }
}
```

→ 클라이언트가 `caps.engines.vllm.supported_options.includes("temperature")` 같은 식으로 사전 검증 가능. 잘못된 옵션은 보내기 전에 차단.
