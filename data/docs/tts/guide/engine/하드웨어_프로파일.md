# Hardware-Specific Audio Profiles

Qwen3-TTS Enterprise는 합성된 음성이 재생되는 **최종 출력 환경(하드웨어)**에 맞춰 실시간으로 오디오를 가공하는 DSP(Digital Signal Processing) 파이프라인을 제공합니다.

---

## 🎧 하드웨어 프로필 리스트

### 1. Standard (Default)
*   **특징**: 모델에서 생성된 오디오를 가공 없이(Normalization 제외) 원본 그대로 전달합니다.
*   **용도**: PC 스피커, 스마트폰, 고품질 이어폰 등 일반적인 환경.

### 2. AICC Optimized (Phone Line)
*   **기술적 처리**:
    *   **Bandpass Filter**: 전화망 가청 대역인 300Hz ~ 3,400Hz를 제외한 불필요한 고/저역대 노이즈 제거.
    *   **Intelligibility Boost**: 사람의 목소리 명료도에 가장 중요한 2kHz 대역을 소폭 증폭.
*   **용도**: 8kHz 샘플레이트 기반의 유선 전화망 상담 시스템, 콜센터 ARS.

### 3. Small Speaker (Kiosk)
*   **기술적 처리**:
    *   **High-pass Filter**: 저음 진동을 견디지 못하는 소형 스피커를 위해 150Hz 이하 대역 제거.
    *   **Presence Boost**: 주변 소음이 심한 키오스크 환경에서도 목소리가 잘 들리도록 3kHz ~ 5kHz 대역 강조.
*   **용도**: 지하철, 마트, 식당 내 키오스크 및 소형 임베디드 스피커.

### 4. Studio Mode
*   **기술적 처리**:
    *   **Dynamic Compression**: 작은 소리는 키우고 큰 소리는 눌러서 전체적인 볼륨을 고르게 맞춤(Normalization 강화).
    *   **Soft Limiting**: 클리핑(소리 깨짐)을 방지하면서도 꽉 찬 소리를 제공.
*   **용도**: 오디오북, 팟캐스트, 전문적인 미디어 콘텐츠 제작.

---

## 🛠️ 기술적 구현 방식
*   본 기능은 `pipeline/audio_processor.py` 엔진을 통해 수행됩니다.
*   `scipy.signal`의 **SOS(Second-order sections)** 필터를 활용하여 연산 속도를 극대화하였으며, 합성 직후 비동기 스레드에서 처리되어 레이턴시 영향이 미미(1~5ms)합니다.
